# YouTube Knowledge Learner — Full English Technical Reference

Use this skill to transform any YouTube video into an authoritative, permanent **English Technical Reference Document**:

1. **Extract transcript & captions** (prioritizing English subtitles; if source video is in Vietnamese or another language, fully translate it into precise technical English).
2. **Preserve ground-truth metadata** and comprehensive timestamp anchors from start to finish.
3. **Distill into a 10-Section In-Depth English Technical Reference Document** (Gold Standard Benchmark, ~8,000–12,000 words / 35–45 KB Markdown).
4. **Auto-compile to interactive standalone HTML (`scripts/build_html.py`)**:
   - Integrated with clean light/dark theme switcher, responsive layout, print/PDF optimization.
   - Built-in **Dual-Mode Visualizer (Executive Bento Grid + Technical Mermaid Flowchart)** with pan, zoom, and fullscreen capabilities.
5. **Operationalize the knowledge** directly into technical architectures, product strategies, or AI agent system prompts.

> If you want a bilingual interactive version (Vietnamese + English toggle), use **`youtube-knowledge-vi-en`**. If you want a 100% Vietnamese translation (all industry terms translated to Vietnamese), use **`youtube-knowledge-vi`**.

## 1. Execution Runbook

### Step 1: Fetch Subtitles & Metadata

Run the dedicated helper script:

```bash
python3 "<SKILL_DIR>/scripts/fetch_youtube_knowledge.py" "<YOUTUBE_URL>" \
  --out "<OUTPUT_DIR>" \
  --lang en \
  --cookies-from-browser chrome \
  --task "<task description if any>"
```

Where:
- `<SKILL_DIR>` = thư mục chứa skill này (Claude Code: `~/.claude/skills/youtube-knowledge-en` hoặc `.claude/skills/youtube-knowledge-en`; Claude.ai / Cowork: thư mục skill được mount cho phiên, hãy dùng đường dẫn thực tế của skill)
- **When running in Claude.ai / Cowork** (no Chrome cookies available): use `--cookies-from-browser none`; if YouTube blocks the request, ask the user to paste the transcript.
- `<OUTPUT_DIR>` = `knowledge/youtube` relative to project root
- `--cookies-from-browser chrome` = uses Chrome session cookies to mitigate YouTube 429 rate-limiting.
- Script returns JSON metadata: `note`, `transcript`, `title`, `source`, `language`, `segments`, `path_used`.

### Step 2: Read Transcript & Author Document

1. Read the raw transcript from `transcript`.
2. Overwrite the generated scaffold at `note` with the full 10-section reference document in **pure, rigorous technical English**.
3. Adhere to the **Molly Graham Gold Standard Benchmark** (detailed below).

### Step 3: Auto-compile to HTML

Run the bundled compiler:

```bash
python3 "<SKILL_DIR>/scripts/build_html.py" "<NOTE_PATH>" --lang en
```

On macOS, open the output directly:
```bash
open "<HTML_PATH>"
```

## 2. Standard Structure — The Gold Standard (Molly Graham Benchmark)

Every document generated by this skill MUST strictly adhere to the following 10-section architecture:

```markdown
# <Video Title in English>

**Source**: <URL> | **Host/Channel**: <Name> | **Recorded**: <YYYY-MM-DD>
**Transcript**: <Official Subtitles | Auto-generated | Local Capture> (<Original Language>)

## 1. Metadata & Quick Reference
- Comprehensive Guest Biography & Career Milestones.
- Complete Table of Metadata (Host, Guest, Duration, URL, Target Audience, Core Disciplines).
- **Quick Index (Timestamp Navigation)**: 15–25 key timestamps paired with precise, descriptive topic summaries.

## 2. Executive Summary
- 5–6 core architectural and strategic takeaways with deep context, empirical evidence, and actionable conclusions.

## 3. Systems Mental Model (Dual-Mode Visualizer REQUIRED)
- Complete Dual-Mode Visualizer implementation according to `references/system-map-template.md`:
  * **Tab 1: ✨ Executive Bento Grid** — High-level architecture cards, step pills, and core axioms.
  * **Tab 2: 🔍 Technical Mermaid Flowchart LR Pipeline** — `flowchart LR` diagram with 4 pastel subgraphs, two-tier mini-cards, and interactive zoom controls.

## 4. Conceptual Lexicon & Technical Taxonomy
- Comprehensive reference table of 8–15 foundational domain concepts with operational definitions, real-world context, and industry significance.

## 5. In-Depth Strategic & Technical Deep Dive
### 5.1 <Theme 1: Deep Analytical Breakdown>
### 5.2 <Theme 2: System Dynamics & Friction Points>
### 5.3 <Theme 3: Counter-Intuitive Models & Structural Tensions>
### 5.4 <Theme 4: Organizational / Technical Mechanics>
### 5.5 <Theme 5: Frontier Paradigms & Long-term Evolution>

## 6. Implementation Frameworks & Step-by-Step Playbooks
- Concrete methodologies, operational protocols, step-by-step decision trees, and tactical playbooks.

## 7. Contrarian Insights & Non-Obvious Truths
- 3–5 non-obvious paradigms, highlighting dogmas challenged by the speaker with comparative table ("Conventional Wisdom" vs "Battle-Tested Reality").

## 8. Trade-Off Matrix & Engineering Evaluation
- Multi-dimensional decision matrix analyzing trade-offs, hidden costs, failure modes, and mitigation tactics.

## 9. The "Fail Corner" & Anti-Patterns
- Crucial failure modes, operational anti-patterns, warning signs, and disaster prevention protocols.

## 10. High-Signal Quotes & Verbatim Excerpts
- 8–12 verbatim quotes capturing decisive wisdom with precise timestamps.
```

## 3. Error Handling Protocols

1. **HTTP 429 / Rate Limited**:
   - Do NOT immediately loop or retry.
   - Instruct the user to ensure Chrome is logged into YouTube, or wait 30–60 minutes for the IP cooldown.
2. **Missing Dependencies**:
   - `yt-dlp`: `brew install yt-dlp` or `pip install yt-dlp`
   - `youtube-transcript-api`: `pip install youtube-transcript-api`
